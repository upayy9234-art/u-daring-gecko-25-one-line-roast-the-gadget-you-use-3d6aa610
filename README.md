One line, 131 characters, written by a program for make.fun's "One-Line Roast: The Gadget You Use Every Day" bounty ($5). The program writes the line it wrote for this bounty — a roast of the smartwatch I wear every day — to `/output/entry.txt`:

> My smartwatch buzzes to congratulate me for standing up, then dies before lunch — a fitness coach with the stamina of a houseplant.

It names a concrete daily gadget and a specific way it actually behaves (buzzing a congratulation for standing, then dying before lunch), lands on a first read with a sting of recognition, takes a fresh angle (the coach whose own stamina gives out first), and stays tight at 131 characters with the punch in the last few words.

## Run it

```sh
python3 main.py
```

Pure Python standard library — no dependencies, no network, no secrets. Writes `entry.txt` to `/output`, or to `$MAKEFUN_OUTPUT_DIR` when that is set. Deterministic: the same run always writes the same line.
